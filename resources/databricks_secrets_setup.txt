DATABRICKS SECRET SCOPE SETUP
==============================

1. INSTALL & CONFIGURE CLI
---------------------------
pip install databricks-cli
databricks configure --token

    Prompts:
    Databricks Host: https://<your-workspace>.azuredatabricks.net
    Token: <your personal access token>

    Generate token: Databricks Workspace > Profile Icon > Settings > Developer > Access Tokens > Generate New Token


2. CREATE SECRET SCOPE
-----------------------
databricks secrets create-scope --scope dw


3. ADD SECRETS
--------------
databricks secrets put --scope dw --key DB_SERVER
databricks secrets put --scope dw --key DB_USER
databricks secrets put --scope dw --key DB_PASSWORD
databricks secrets put --scope dw --key DB_DATABASE

    Note: Each command opens a text editor. Type the value, save, and close.


4. VERIFY SECRETS (keys only, values are never exposed)
--------------------------------------------------------
databricks secrets list-scopes
databricks secrets list --scope dw


5. VERIFY VALUES (run inside a Databricks notebook)
----------------------------------------------------
server = dbutils.secrets.get(scope="dw", key="DB_SERVER")
print(len(server))   # check length
print(server[:5])    # check first few characters


6. TEST CONNECTION (run inside a Databricks notebook)
------------------------------------------------------
from config import get_db_config
from utils.db_connection import get_connection

cfg = get_db_config()
spark, jdbc_url, props = get_connection(cfg)
df = spark.read.jdbc(url=jdbc_url, table="INFORMATION_SCHEMA.TABLES", properties=props)
df.show(5)


7. UPDATE A SECRET (if value was entered incorrectly)
------------------------------------------------------
databricks secrets put --scope dw --key DB_PASSWORD


8. DELETE A SECRET
------------------
databricks secrets delete --scope dw --key DB_PASSWORD


9. DELETE THE ENTIRE SCOPE
---------------------------
databricks secrets delete-scope --scope dw
